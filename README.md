# 🌦️ WeatherPro AI

A modern AI-powered weather application that delivers real-time weather information, forecasts, and intelligent recommendations to help users plan their day more effectively.

## 🚀 Live Demo

🌐 Live Website: http://127.0.0.1:5500/

---

## 📖 Overview

WeatherPro AI is designed to provide users with accurate weather information through a clean and responsive interface. The application combines weather data with AI-driven insights to create a smarter weather experience.

Whether you're planning travel, outdoor activities, or your daily schedule, WeatherPro AI helps you make informed decisions based on current and forecasted weather conditions.

---

## ✨ Features

* 🌍 Search weather for any city worldwide
* 📍 Automatic location detection
* 🌡️ Real-time temperature updates
* ☁️ Current weather conditions
* 💧 Humidity information
* 💨 Wind speed monitoring
* 🌅 Sunrise and sunset details
* 🤖 AI-powered weather insights
* 📱 Fully responsive design
* ⚡ Fast performance and modern UI
* 🎨 Clean and user-friendly interface
